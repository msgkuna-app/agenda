Konfigurasi Firebase Belum Diisi

Berkas public/js/firebase-config.js masih berisi nilai penanda ISI_DARI_FIREBASE_CONSOLE. Aplikasi ini tidak menggunakan mode demo atau data palsu.

  1. Buka Firebase Console pada proyek Anda, lalu masuk ke Project settings → General.
  2. Pada bagian Your apps, salin objek firebaseConfig dari aplikasi Web Anda.
  3. Buka berkas public/js/firebase-config.js dan ganti seluruh nilai "ISI_DARI_FIREBASE_CONSOLE" dengan nilai asli proyek Anda.
  4. Pastikan penyedia masuk Google sudah aktif di menu Authentication → Sign-in method untuk akun pemilik msgkuna.app@gmail.com.
  5. Muat ulang halaman ini setelah menyimpan perubahan.
